## 引言
本故障排除文档面向 H.AppLab 平台的运维、开发与测试人员，目标是帮助快速定位并修复环境、配置、性能、数据库、后台任务、安全入侵等典型问题。平台基于 .NET + Blazor 模块化架构，支持单体部署和按服务独立部署；包含低代码设计引擎、渲染引擎、账户、组织、审批、通知、订单、供应链、测试等多个业务服务，以及 Hangfire 后台任务和 MinIO 对象存储等外部依赖。

## 项目结构与排障范围
H.AppLab 的排障范围主要覆盖以下层面：
- 运行环境与 SDK：.NET SDK 版本由 `global.json` 锁定为 10.0.0，并通过 `rollForward: latestFeature` 允许滚动到同主版本的最新特性版本。
- Web 宿主与中间件：Blazor Server + WebAssembly、SignalR、响应压缩、静态资源缓存、异常处理、HTTPS 重定向、Hangfire 仪表盘等。
- 配置中心：应用连接字符串、远程服务地址、MinIO、外部登录、站点列表、日志级别等。
- 数据库层：多个 EF Core DbContext 对应不同业务库，通过 DbMigrator 工具执行迁移。
- 后台任务：Hangfire + SQL Server 作业存储，提供定时、延迟、一次性任务调度与执行记录。
- 外部依赖：Redis、RabbitMQ、MinIO、第三方开放 API（如阿里云 RDC OpenAPI）。

## 常见问题分类与处理方案

### 一、环境问题
#### 1.1 SDK 版本不兼容
- 现象
  - 无法编译或运行时提示 .NET SDK 版本不匹配。
  - 本地开发命令执行失败，或发布产物运行异常。
- 诊断
  - 检查 `global.json` 中的 SDK 版本是否与实际安装的 .NET SDK 一致。
  - 确认未启用错误兼容模式导致解析到非预期 SDK。
- 解决
  - 安装与 `global.json` 一致的 .NET 10 SDK。
  - 若需滚动到同主版本最新特性，保持 `rollForward: latestFeature` 即可。
  - 清理 `bin/obj` 后重新还原包与构建。

**章节来源**
- [global.json:1-6](file://src/global.json#L1-L6)

#### 1.2 依赖服务连接失败
- 现象
  - 启动时报数据库连接失败、Redis/RabbitMQ 不可用、MinIO 上传失败。
  - 控制台输出连接超时、认证失败、SSL/TLS 证书错误。
- 诊断
  - 根据报错信息判断缺失的外部依赖。
  - 检查 Docker Compose 是否启动成功，端口是否被占用。
  - 验证网络连通性与防火墙规则。
- 解决
  - 启动依赖服务：Redis、RabbitMQ、MinIO、SQL Server。
  - 修正连接地址、用户名、密码、虚拟主机、队列名、桶名等参数。
  - 如需 HTTPS，确保证书有效且受信任。

### 二、配置问题
#### 2.1 数据库连接字符串错误
- 现象
  - 应用启动失败、接口频繁报数据库连接异常、迁移失败。
- 诊断
  - 检查 `appsettings.json` 中 `ConnectionStrings` 下的各数据库连接串。
  - 确认 SQL Server 实例名称、数据库名、身份验证方式正确。
  - 确认迁移工具 `appsettings.json` 中的连接串与服务端一致。
- 解决
  - 修正连接字符串，确保 `(localdb)\mssqllocaldb` 或生产数据库地址可达。
  - 使用对应服务的 DbMigrator 执行数据库迁移。
  - 校验 TrustServerCertificate、Encrypt、Timeout 等参数是否符合环境要求。

### 三、性能问题
#### 3.1 内存泄漏
- 现象
  - 进程内存持续增长，长时间运行后 OOM。
- 诊断
  - 使用 .NET 内存分析工具抓取堆快照。
  - 排查长生命周期对象、事件订阅未释放、HttpClient 未复用、流未关闭。
  - 重点检查后台任务执行器、HTTP 客户端、文件流、数据库连接。
- 解决
  - 确保 `IHttpClientFactory` 创建的客户端被复用而非每次新建。
  - 避免在循环中持有大对象引用。
  - 及时释放流、取消令牌、信号量等资源。
  - 对后台任务增加执行耗时与结果长度限制。

#### 3.2 CPU 占用过高
- 现象
  - 服务启动慢、页面卡顿、接口响应变慢。
- 诊断
  - 使用性能分析工具采集热点方法、GC 行为、线程状态。
  - 检查是否存在同步阻塞、死循环、正则回溯、大量 JSON 序列化。
  - 检查 Hangfire 任务堆积、重复调度、重试风暴。
- 解决
  - 异步化阻塞操作。
  - 调整 Hangfire 并发度与队列策略。
  - 优化查询语句、分页大小、批量操作。
