仓库采用 Blazor Web App（Server + WebAssembly Client）的模块化架构，支持单体部署与按服务独立部署两种模式：Host 层仅做服务注册；LowCode 提供设计引擎与设计端应用（Workbench、MyApp）；Services 按限界上下文划分企业级业务模块，每个模块遵循 Application.Contracts / Application / EntityFrameworkCore / Web 分层；System 提供平台运营侧应用；Tools 为各服务的 DbMigrator；Utils 沉淀跨项目共享库（IAppService 动态代理、Blazor 工具等）。前端通过 H.Abp.HttpClientProxy 基于 IAppService 接口自动生成 HTTP 调用，实现服务端进程内与客户端 WebAssembly 无感切换，并配合 BlazorWebAssemblyLazyLoad 与 LazyModuleRegistry 实现路由级懒加载与组合式 DI。
