需先准备 .NET SDK（版本见 src/global.json）、WSL + Docker + Portainer；将仓库下的 docker-compose.yml 复制到 WSL 后 `sudo docker-compose up -d` 启动 Redis/RabbitMQ 等依赖；数据库通过 Tools 下对应 DbMigrator 创建，例如 `dotnet run --project src/Tools/H.Account.DbMigrator`；主程序以 `dotnet run --project src/Host/H.AppLab.Host.All/H.AppLab.Host.All --launch-profile HostAll` 启动，默认 http://localhost:5045（https 7065）。
